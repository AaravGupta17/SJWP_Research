# Data book notes

Handwritten notes for `docs/DATA_BOOK.md`. Name each file after the run record it belongs to,
for example `2026-09-23_202146_e4_mendeley_eval.md` for
`results/runs/2026-09-23_202146_e4_mendeley_eval.json`. Then run
`python scripts/make_data_book.py`, which inserts the note under that run's entry.

A useful note answers three questions:

1. **Why** was this run? (Which question or hypothesis?)
2. **What** does the result show, including what it does *not* show?
3. **What next?** What was changed or decided because of it?

Write these yourselves, on or close to the day of the run: the data book is your own record.
